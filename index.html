🌐 Networking

  • Public ↔ Internet → IGW
  • Private → Internet → NAT
  • Private → OCI service → Service Gateway
  • Hybrid/transit → DRG
  • Encrypted over Internet → VPN
  • Dedicated/private → FastConnect

🔐 IAM

  • Humans → Groups
  • Resources → Dynamic Groups
  • VM auth → Instance Principal
  • inspect < read < use < manage
  • Any compartment → in tenancy

💾 Storage

  • Disk → Block
  • Shared NFS → File
  • Unstructured → Object
  • IA = 31 days
  • Archive = 90 days + restore
  • PAR / Versioning / Retention son cosas distintas

🖥️ Compute

  • Known time → Schedule-based
  • CPU threshold → Metric-based
  • Kernel no reboot → Ksplice
  • Interruptible → Preemptible
  • Guaranteed capacity → Capacity Reservation

🧭 DNS + LB

  • Listening = receives
  • Forwarding = sends
  • NLB = L3/L4
  • Health Check = backend health
  • Listener = protocol + port

🚨 HA / DR

  • Rack/hardware → Fault Domain
  • Datacenter isolation → Availability Domain
  • Regional disaster → Cross-region
  • RPO = data loss
  • RTO = recovery time

        ↓

        ↓

        ↓
5. If two still work: cost / availability / operational overhead decides.
