# OCI Architect Associate - Master Study System

Sitio de estudio visual e interactivo preparado para GitHub Pages.

## Publicar con GitHub Pages
1. Crea un repositorio nuevo en GitHub, por ejemplo `oci-architect-study`.
2. Sube todo el contenido de esta carpeta a la raiz del repositorio.
3. En GitHub abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama **main** y la carpeta **/(root)** y pulsa **Save**.
6. GitHub mostrara la URL publica del sitio cuando termine el despliegue.

El archivo principal es `index.html`. No requiere compilacion ni dependencias.
