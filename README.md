# OCI Architect Associate — Simulador de escenarios

Sube los archivos de esta carpeta a la **raíz** de un repositorio GitHub (no la carpeta contenedora). En Settings → Pages → Deploy from a branch, elige main y /(root). Abre la URL HTTPS en Safari. Para usar sin conexión después de la primera carga, agrega a pantalla de inicio.

Incluye 36 casos originales de práctica, modo práctica y examen, explicación de todas las opciones y progreso local. No son preguntas oficiales ni garantiza aprobación.
